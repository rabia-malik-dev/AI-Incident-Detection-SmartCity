# Backend (ASP.NET Core Web API)

Orchestrates uploads, processing jobs, JWT auth, EF Core + SQL Server, and HTTP calls to `ml-service`.

**Scaffold:** `dotnet new webapi` in this folder (.NET 8) — Phase 3 in [IMPLEMENTATION-ROADMAP](../docs/IMPLEMENTATION-ROADMAP.md).

Swagger at `/swagger`. Does not expose ML directly to the browser.
